일본어 단어 시험지

단어 3열을 붙여넣고, 같은 순서의 시험지·답지 PDF를 만드세요.

페이지를 닫으면 입력 내용과 생성 순서는 사라집니다.

1. 단어 붙여넣기

한 줄에 단어 하나씩, 한자 · 읽는 법 · 뜻 순서로 입력하세요. 열은 탭, 쉼표 또는 세로줄로 구분할 수 있습니다.

권장 형식: 漢字[TAB]よみ[TAB]뜻

단어를 붙여넣어 주세요.

예: 1을 입력하면 시험지와 답지의 제목이 Day01-1부터 Day01-6까지 표시됩니다.

2. 인식된 단어 표

아직 인식된 단어가 없습니다.

붙여넣은 뒤 단어 표 만들기를 누르면
여기에 한자, 읽는 법, 뜻이 표시됩니다.

한 번 누르면 새 무작위 6세트를 만든 뒤, 시험지 인쇄 창과 답지 인쇄 창을 차례로 엽니다.
